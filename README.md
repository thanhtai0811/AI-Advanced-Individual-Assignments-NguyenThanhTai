## Mục đích

Repository được sử dụng để:

- Lưu trữ tập trung các bài tập cá nhân trong suốt quá trình học.
- Phân loại bài tập theo từng chủ đề của môn học.

- Cung cấp một cấu trúc rõ ràng, thuận tiện cho việc kiểm tra và đánh giá.
